## Project title
A High Load E-Commerce API Service

## Motivation
This project is made to help me grasp how to server large amount of users simultaneously. The motivation behind this project, is that my company is collaborating with an Indonesian E-Commerce platform. So in advance, I have to learn and prepare on how to handle such massive amount of users trying to hit our services.
